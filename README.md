## 🚀 طريقة الاستعمال

1. افتح **Steal a Brainrot** + **Delta**.
2. انسخ محتوى `src/StealABrainrot.lua` والصقه واضغط **Execute**.
3. النافذة تفتح على تاب **Eggs** (تتصغر بـ `–`، تتقفل بـ `✕`، وترجع بالزر العايم ☰).

### تاب Eggs (الرئيسي)
| القسم | شنو فيه |
|---|---|
| **Status** | كم بيضة تّلقات • كم عدّات التصفيات • كم وصّلت للقاعدة |
| **Detection** | تشغيل ESP، صندوق توهّج، رؤية عبر الحيطان، الحساسية (عادي/واسع/صارم)، **DEEP SCAN NOW**، كلمات بحث إضافية |
| **Filters** | أقل ندرة • الجزيرة • البحث بالاسم • أقصى مسافة • إخفاء المجهول • تخطّي الفاشل • **RESET** |
| **Eggs found** | قايمة حيّة **مجمّعة بالتصنيف** (رأس ملوّن لكل ندرة) — **اضغط عليها = تيليبورت**، وزر **FARM** = يجيبو للقاعدة |
| **Alerts** | شغّل التنبيه واختار من أي ندرة (مثلاً `Secret`) |
| **Islands** | أزرار للجزر المكتشفة: طيران + عدد البيضات |
| **Collected eggs** | سجل البيضات اللي جبتها |
| **AFK / XP** | قفز تلقائي على الترامبولين (XP بلا تعب) |
| **Auto farm** | تشغيل/إيقاف • ترتيب الاختيار (أحسن ندرة / الأقرب / أحسن دخل) • **SET BASE HERE** • FARM BEST / NEAREST |

### تاب Diag (التشخيص) — **أهم حاجة نحتاجها منك**
إذا باقي ما تلقى البيضات:
1. ادخل منطقة الـ LTM (البوابة).
2. تاب **Diag** ← **BUILD FULL REPORT**.
3. **COPY report** (أو SAVE إلى `SaBSuite/egg_report.txt`).
4. صيفطولي → نحطّ الأسماء التقنية الحقيقية ونخلي الرصد 100%.

### تاب Sniper
- **TEST: listen to everyone** + اكتب بالشات `code is` ثم `TACO` ثم `BOOST` → تشوفو يكتب الكود خطوة بخطوة.
- الأنواع السبعة موجودين؛ والسكريبت يقرا النوع من كلام Sammy تلقائياً.

## 🥚 كيف يشتغل الرصد (باختصار)

كل شيء داخل الـ workspace يتقيّم بـ **نقاط (0–100)**، واللي يجيب **60 أو أكثر** يتّعتابر بيضة:

| المصدر | النقاط | مثال |
|---|---|---|
| `db` — الاسم يطابق واحد من الـ 35 بيضة | 100 | `DragonCannelloni`، `Egg_Cerberus` |
| `value` — قيمة/خاصية فيها اسم برينروت | 95 | `EggName = "Cerberus"` |
| `attr` — خاصية `IsEgg = true` | 85 | `MysteryCapsule` |
| `name` — كلمة «egg» باسمو | 70 | `Egg_1` |
| `user` — كلمة من كلماتك | 65 | `capsule` |
| `prompt` — عندو برومبت «Collect/Grab/Pick» | 58 | بيضة بلا اسم واضح |
| داخل مجلد `Eggs/Islands/LTM` | **+12** | يرفّع أي إشارة حقيقية |

استثناءات ذكية: الجزر نفسها (`GrassIsland`…) ما تتّعتابرش بيضة، والأجزاء الداخلية للبيضة ما تتكرّرش.
تفاصيل أكثر: [`docs/egg-detection.md`](docs/egg-detection.md).
