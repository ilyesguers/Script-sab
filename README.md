## 🚀 طريقة التشغيل
1. افتح **Steal a Brainrot** + **Delta**.
2. انسخ محتوى `src/StealABrainrot.lua` والصقه بـ Delta واضغط **Execute**.
3. تفتح قائمة إنجليزية (تنزّل/تنقل/تتصغر) مناسبة للموبايل والكمبيوتر.
4. اذهب لتاب **Explorer** واضغط أزرار الـ Dump → أرسل لي النتيجة عشان نحط الأسماء التقنية الحقيقية.

## 🧪 اختبار القناص (بدون أدمن أبوس!)
تاب **Code Sniper** → TEST ZONE:
- **1) Feed this word** → تغذي كلمة (مثل `TACO`) وتشوف كيفayah يصنّفها (WORD / LETTER / DIGITS / NUMBER_WORD / DOUBLE).
- **2) Start session** → يبدأ وضع التجميع.
- **3) Play DEMO** → يسلسل تلقائي: `code is` → `TACO` → `BOOST` → `123`.
- **4) Force finish** → ينهي التجميع فوراً.
- أو شغّل **"TEST: listen to everyone"** واكتب بالشات العادي: `code is` ثم `TACO` ثم `BOOST` ثم `123` → تشوفه يكتب بالخانة خطوة خطوة.
